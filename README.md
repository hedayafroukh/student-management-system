# Student Management System

## Project
A simple Student Management System built using HTML, CSS, and JavaScript. It allows users to add, edit, delete, search, filter, and sort students. Student data is saved using Local Storage.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Local Storage

## Features
- Add students
- Edit students
- Delete students
- Search by name or ID
- Filter by major
- Sort by GPA
- Save data in Local Storage
